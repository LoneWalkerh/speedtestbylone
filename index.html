FREQUENTLY ASKED QUESTIONS

Everything You Need to Know

How do the download buttons work? +
Both download buttons provide direct binary file downloads. The Windows Installer (.exe) installs Speedtest Pro into your Windows Start Menu and Desktop with clean uninstallation support. The Portable Version (.exe) runs instantly upon double-clicking with zero installation needed.
How does Speedtest Pro bypass Ookla rate limits? +
Official Ookla speedtest clients track device identifiers that frequently trigger HTTP 429 "Limit reached" bans when running repeated benchmarks. Speedtest Pro embeds a binary-patched engine token that safely isolates each session, guaranteeing uninterrupted high-speed testing.
Does it support multi-gigabit connections (1 Gbps+ / 2 Gbps+)? +
Yes! The application features dynamic scale switching. If your line speed surpasses 500 Mbps, the gauge automatically re-indexes to a 1,000 Mbps scale. If speeds exceed 1,000 Mbps, it seamlessly expands to a 2,000 Mbps scale with full real-time needle and sparkline tracking.
Where is my test history stored? +
All benchmarks are securely stored in your local user application directory (`~/.speedtest_history.json`). No benchmarks are sent to external servers or third parties, and you can export your entire test history to CSV with one click.
